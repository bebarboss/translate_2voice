# คู่มือผู้ใช้ Pakdee (พากย์ดี)

คู่มือนี้สำหรับผู้ใช้หน้าเว็บ — อัปโหลดคลิป ตรวจบท พากย์ และดาวน์โหลดผลลัพธ์

---

## 1. Pakdee คืออะไร

Pakdee แปลงคลิปภาษาต่างประเทศเป็นคลิปพากย์ไทยหรืออังกฤษ โดยระบบจะ

1. แยกเสียงพูดออกจากเพลง  
2. แยกว่าใครพูดตอนไหน  
3. ถอดเสียงแล้วแปลบทให้พอดีเวลาในฉาก  
4. พากย์ด้วยเสียงโคลนจากต้นฉบับ หรือเสียงจากคลัง  
5. รวมวิดีโอ พร้อมไฟล์ซับและเลเยอร์เสียงแยก  

เหมาะกับคลิปละคร อนิเมะ สัมภาษณ์ รีวิวสินค้า ฯลฯ

---

## 2. เริ่มต้นใช้งาน

### 2.1 สมัคร / เข้าสู่ระบบ

1. เปิดหน้าเว็บ Pakdee  
2. กดสมัครหรือเข้าสู่ระบบ (เช่น Google)  
3. กรอกข้อมูลเบื้องต้น (ชื่อ เบอร์ ประเภทผู้ใช้) และยอมรับข้อกำหนด  

### 2.2 รับแพ็กทดลอง

หลังเข้าสู่ระบบ ไปที่หน้าโปรโมชันหรือบัญชี แล้วรับ **แพ็กทดลอง** ได้ครั้งเดียวต่อบัญชี

| รายการ | ค่า |
|---|---|
| เครดิตฟรี | 2 เครดิต |
| อายุ | 30 วัน |
| ความยาวคลิปสูงสุด | 2 นาที |
| ลายน้ำ | มีบนวิดีโอผลลัพธ์ |

### 2.3 เครดิตคิดอย่างไร

- **1 เครดิต = คลิป 1 นาที** ตามความยาวจริง (เช่น 1:15 นาที = 1.25 เครดิต)  
- ตัดเครดิตตอน**เริ่มวิเคราะห์** ไม่ใช่ตอนพากย์ซ้ำ  
- แก้บทแล้วพากย์ใหม่**ไม่เสียเครดิตเพิ่ม**  
- วิเคราะห์ไม่สำเร็จ → ได้เครดิตคืน  
- ใช้เครดิตแพ็กเกจก่อน แล้วค่อยใช้เครดิตเติม  

ซื้อแพ็กหรือเติมเครดิตได้ที่หน้าบัญชี / โปรโมชัน

---

## 3. ส่งคลิปพากย์

หน้าแรก `/` หรือปุ่ม **ส่งคลิปใหม่**

### 3.1 เลือกแหล่งคลิป

- **อัปโหลดไฟล์** — `.mp4` `.mov` `.mkv` `.webm` `.avi` `.m4v`  
- **วางลิงก์** — YouTube, TikTok, Facebook, Bilibili ฯลฯ  

### 3.2 ตั้งค่าก่อนส่ง

| ช่อง | คำอธิบาย |
|---|---|
| ภาษาต้นฉบับ | ว่าง = ให้ระบบตรวจเอง หรือระบุถ้ามั่นใจ |
| ภาษาพากย์ | ไทย หรือ อังกฤษ |
| จำนวนตัวละคร | ถ้ารู้ ให้ใส่ — แยกผู้พูดแม่นขึ้น |
| แนวเรื่อง | เช่น การ์ตูนเด็ก ละครจีน — ช่วยการแปล |
| คำศัพท์เฉพาะ | บรรทัดละคำ เช่น `ドラえもん = โดราเอมอน` |
| ตรวจบทก่อนพากย์ | แนะนำเปิดไว้ สำหรับงานจริง |
| ฝังซับ | ฝังซับลงวิดีโอผลลัพธ์ (ปรับรูปแบบได้ทีหลัง) |
| โปรเจกต์ | ถ้ามีโปรเจกต์ซีรีส์ ให้เลือก เพื่อจำตัวละครข้ามตอน |

กดส่งแล้วรอระบบวิเคราะห์ (แยกเสียง → ถอดเสียง → แปล)

## 4. ตามงานและความคืบหน้า

หน้า **งานทั้งหมด** `/jobs`

- กรองตามสถานะ: กำลังทำ / รอตรวจบท / เสร็จ / ล้มเหลว  
- ระหว่างทำงาน: เปิดงานนั้นเพื่อดูขั้นและความคืบหน้า  
- **ยกเลิก** ได้ระหว่างคิวหรือกำลังรัน  
- **ลองใหม่** ได้เมื่องานล้มเหลวหรือถูกยกเลิก  
- **ลบ** งานและไฟล์ทั้งหมด (กู้คืนไม่ได้)

| สถานะ | ความหมาย | ขั้นถัดไป |
|---|---|---|
| กำลังประมวลผล | วิเคราะห์หรือพากย์อยู่ | รอ หรือยกเลิก |
| รอตรวจบท | แปลเสร็จ รอคุณแก้บท | แก้บท แล้วกดพากย์ |
| เสร็จ | มีวิดีโอพากย์แล้ว | ดาวน์โหลด / แก้บทพากย์ใหม่ |
| ล้มเหลว | มีข้อผิดพลาด | ลองใหม่ หรือส่งคลิปใหม่ |

---

## 5. ตรวจบทก่อนพากย์ (สำคัญ)

เมื่อสถานะเป็น **รอตรวจบท** หน้างานจะแสดงวิดีโอต้นฉบับคู่กับบทแปล

### สิ่งที่ควรทำ

1. เล่นคลิป ดูซับและรายการประโยคทางขวา  
2. แก้คำแปลให้สั้น พอดีปาก และถูกบริบท  
3. เปลี่ยนตัวละครของประโยคถ้าระบบจัดคนผิด  
4. ตั้งชื่อตัวละคร (เช่น โนบิตะ) เพื่อให้อ่านง่าย  
5. เลือกเสียงจากคลังให้ตัวละคร (ถ้าต้องการ) หรือใช้เสียงโคลนจากต้นฉบับ  
6. กด **บันทึกและเริ่มพากย์**

ระบบจะบันทึกการแก้ทั้งหมดก่อน แล้วเข้าคิวพากย์

### เคล็ดลับตรวจบท

- ใส่ชื่อเฉพาะในช่องคำศัพท์ตั้งแต่ตอนส่งคลิป  
- ท่อนสั้นมาก / เพลงจบตอน / เสียงเอฟเฟกต์ — ลบหรือรวมกับท่อนข้าง ๆ  
- บทยาวเกินช่องปาก → ย่อเอง หรือให้ระบบย่อตอนแปล  
- ถ้ามีหลายคนพูด ตรวจว่าสี/ชื่อตัวละครสลับถูกต้อง  

---

## 6. ผลลัพธ์และดาวน์โหลด

เมื่องาน **เสร็จ** จะดาวน์โหลดได้ประมาณนี้

| ไฟล์ | เนื้อหา |
|---|---|
| วิดีโอพากย์ | MP4 เสียงพากย์ + เพลงเดิม |
| ซับ `.srt` | ไฟล์ซับแยก |
| ZIP | วิดีโอ + ซับ รวมกัน |
| เลเยอร์เสียง | เสียงแต่ละตัวละคร, เพลง, เสียงพากย์ล้วน, เสียงผสม |

ปรับรูปแบบซับ (ฟอนต์ สี ขนาด ตำแหน่ง) แล้วฝังซับใหม่ได้โดยไม่ต้องพากย์ซ้ำ

### แก้หลังพากย์แล้ว

1. เปิดงานที่เสร็จแล้ว  
2. เข้าโหมดแก้บท  
3. แก้เฉพาะประโยคที่ต้องการ  
4. กด **บันทึกและพากย์ใหม่**  

ระบบพากย์เฉพาะประโยคที่เปลี่ยน ประหยัดเวลาและไม่เสียเครดิตเพิ่ม

## 7. คลังเสียง

หน้า `/voices`

- เลือกเสียงพากย์ไทยที่มีในระบบมาผูกกับตัวละครในงาน  
- บางเสียงมีหลายอารมณ์ (โกรธ เศร้า สุข ฯลฯ)  
- แพ็กทดลองใช้ได้เฉพาะเสียงมาตรฐานที่แอดมินเปิดไว้  

ถ้าต้องการส่งเสียงตัวเองเข้าระบบ ใช้หน้าสมัครนักพากย์ (`/actor`) — ผู้ดูแลอนุมัติก่อนถึงจะขึ้นคลัง

---

## 8. โปรเจกต์ (หลายตอน)

หน้า `/projects`

ใช้เมื่อพากย์ซีรีส์หลายตอนที่ตัวละครชุดเดิม

1. สร้างโปรเจกต์ ตั้งภาษาพากย์  
2. ส่งคลิปโดยเลือกโปรเจกต์นั้น  
3. ระบบช่วยจับคู่ตัวละครข้ามตอนจากลายเสียง  
4. ตั้งชื่อและเสียงพากย์ประจำตัวละครในโปรเจกต์  

---

## 9. การตั้งค่า

หน้า `/settings` (และแท็บการตั้งค่าในบัญชี)

- ภาษาพากย์เริ่มต้น  
- เปิด/ปิดตรวจบทก่อนพากย์  
- ฝังซับเป็นค่าเริ่มต้น  
- ความดังเสียงพากย์ vs เพลง  
- ความเร็วสูงสุดที่ยอมให้เร่งเสียง  
- คุณภาพเสียงพากย์ (เร็ว / ปกติ)  
- รูปแบบซับเริ่มต้น  

ค่าเหล่านี้ใช้กับงานใหม่ ไม่ย้อนแก้งานเก่าอัตโนมัติ

---

## 10. บัญชีและความเป็นส่วนตัว

หน้า `/account`

- แก้โปรไฟล์  
- ดูเครดิต ประวัติการใช้ ซื้อแพ็ก/เติมเครดิต  
- ดาวน์โหลดสำเนาข้อมูลบัญชี  
- ปิดบัญชี (ลบข้อมูลตาม PDPA — เครดิตที่เหลือไม่คืนเป็นเงิน)

## 11. คำถามที่พบบ่อย

**พากย์แล้วเสียงไม่ตรงบท**  
แก้บทนั้นให้ชัดขึ้น แล้วพากย์ใหม่เฉพาะท่อน หรือฟังต้นฉบับแล้วเขียนใหม่สั้นลง

**ตัวละครสลับคน**  
ตอนตรวจบท เปลี่ยนป้ายผู้พูดทีละประโยค แล้วพากย์ใหม่

**เครดิตไม่พอ**  
รับแพ็กทดลอง (ถ้ายังไม่เคย) หรือซื้อแพ็ก/เติมเครดิต

**ลิงก์ดาวน์โหลดไม่ได้**  
ลองอัปโหลดไฟล์แทน หรือตรวจว่าลิงก์สาธารณะดูได้โดยไม่ล็อกอิน

**งานล้มเหลว**  
กดลองใหม่ ถ้าซ้ำ ให้ส่งคลิปสั้นลง หรือระบุภาษาต้นฉบับ

**มีลายน้ำ**  
แพ็กทดลองมีลายน้ำ — ซื้อแพ็กเสียเงินเพื่อเอาลายน้ำออก

---

## 12. ข้อจำกัดที่ควรรู้

- คลิปเพลงดังทับคำพูดมาก ถอดเสียงอาจตกหล่น  
- อนิเมะที่มี OP/ED / ตะโกน / เอฟเฟกต์ — ควรตรวจบทก่อนพากย์เสมอ  
- จำนวนตัวละครมากและเสียงคล้ายกัน อาจรวมคนผิดได้ แก้ตอนตรวจบทได้  
- คุณภาพขึ้นกับความชัดของต้นฉบับและความถูกต้องของบทที่คุณตรวจ  

---

## 13. เส้นทางใช้งานแบบย่อ

```
สมัคร → รับทดลอง 2 เครดิต
  → ส่งคลิป (เปิดตรวจบท)
  → รอวิเคราะห์
  → ตรวจ/แก้บท + ตัวละคร + เสียง
  → บันทึกและเริ่มพากย์
  → ดาวน์โหลดวิดีโอ / ซับ / เลเยอร์
  → (ถ้าต้อง) แก้บางประโยค แล้วพากย์ใหม่เฉพาะท่อนนั้น
```

หากติดปัญหาการใช้งาน ใช้หน้าสนับสนุนในเว็บ หรือติดต่อผู้ดูแลระบบที่ให้บัญชีคุณ
